Pre-buy against production

Fabric is ordered months early (the pre-buy), before the collection is final. Once styles and quantities are decided, production orders follow. This page lines the two up, fabric by fabric and colour by colour, and shows what is over, what is short, and what it is worth.

01Read the order exportSeason code “PB1” = pre-buy; no PB = production. Cancelled lines are left out.
02Split the codeFirst 7 digits = the fabric, last 4 = the colour. 2790 = undyed, ready to dye.
03CompareMetres pre-bought vs metres production needs, for the fabric in all colours, then per colour.
04ActOver: cut what hasn't shipped, the rest goes to the library. Short: top up now, against the mill's lead time.

How did this quality sell?

Sell-through of past styles in the same fabric quality, from Power BI, does two things at pre-buy: it moves each new style's survival odds, and it flags fast sellers whose fabric has a long lead time, so undyed (RTD) fabric can be held for a reorder.

01Sales by stylePower BI sell-through of past styles, grouped by base fabric (first 7 digits).
02Signal per qualityUnit-weighted sell-through vs the 60% median.
03Survival oddsLine-review base rate for the category, moved ±0.5 pt per point of signal (max ±15).
04Commit + holdFirm tranche = need × odds, stock used first. Fast + long lead time → hold RTD.
